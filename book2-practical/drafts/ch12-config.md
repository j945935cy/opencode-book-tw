# 第 12 章：設定系統

OpenCode 的設定系統設計目標很明確：預設值夠好到可以完全不設定，又允許你把每一層行為調成自己的形狀。這章建立完整的設定心智模型——七層來源如何疊加、誰覆蓋誰——然後講兩個最能改變日常手感的擴充點：自訂指令與快捷鍵。

## 12.1 設定檔位置與格式

設定檔是 JSON（支援含註解的 JSONC 變體），兩個主要位置：

| 層級 | 路徑 | 用途 |
|------|------|------|
| 全域 | `~/.config/opencode/opencode.json` | 個人偏好，跨所有專案 |
| 專案 | `<專案>/.opencode/opencode.json` | 團隊規範，隨儲存庫版控 |

兩份都存在時會合併，衝突時專案合併，衝突時專案層勝出。檔案頂部建議永遠帶上 schema 宣告，編輯器就會提供欄位自動補全與校驗：

```json
{
  "$schema": "https://opencode.ai/config.json"
}
```

TUI 相關的偏好（主題等）另有一份 `~/.config/opencode/tui.json`，由 `/themes` 等介面操作自動維護，通常不必手編。

## 12.2 七層設定合併優先序

同一個選項可能同時出現在多處。OpenCode 的合併規則可以用一張優先序表記住，數字越大越後套用、越有話語權：

| 層 | 來源 | 典型內容 |
|----|------|----------|
| 1 | 內建預設值 | 一切的地基 |
| 2 | 全域設定 `~/.config/opencode/` | 個人習慣：主題、常用模型 |
| 3 | XDG 相容路徑 `$XDG_CONFIG_HOME` | 特殊環境的替代全域位置 |
| 4 | 專案設定 `.opencode/opencode.json` | 團隊規範：權限、技能、代理 |
| 5 | 額外指定檔案（`--config` 參數） | 實驗性或場景化設定檔 |
| 6 | 代理／模式定義 | 某個代理自己的模型或工具覆寫 |
| 7 | CLI 旗標 | 臨時覆蓋一切，只影響本次執行 |

三條推論值得寫進肌肉記憶：

- **越靠近「執行的當下」優先權越高**——所以臨時實驗用旗標（第 7 層），長期共識用專案檔（第 4 層）。
- **團隊規範要防個人覆蓋**的話沒有技術手段，靠 code review 盯 `.opencode/` 的變更（它本來就該進版控）。
- 不確定目前生效的是哪一份設定時，從第 7 層往下逐層排查；大多數「我的設定怎麼沒生效」案例都是高層被更高層覆蓋了。

## 12.3 自訂指令與快速鍵

**自訂指令：你的斜線命令**

把常用的複雜提示詞存成一個 Markdown 檔，之後一個 `/名字` 就能叫用：

```markdown
---
description: 全面檢查未提交變更並產生審查報告
---
請以資深審查者角度檢查目前的 git 未提交變更：

1. 逐檔列出變更摘要與風險等級（高／中／低）
2. 標出任何可能的邊界條件遺漏
3. 檢查是否漏了對應測試，缺則列出建議測試案例
4. 最後給出「可合併／需修改」結論與理由

不要直接修改任何程式碼。
```

存放位置與生效範圍：

- 專案級：`.opencode/command/review.md` → TUI 輸入 `/review`
- 全域級：`~/.config/opencode/command/review.md` → 所有專案可用

指令檔還支援參數佔位，讓命令像小函式一樣收輸入（詳見第四冊）。指令與技能的分工再強調一次：**指令是你明確叫用的流程，技能是 AI 自動比對觸發的知識**。

**快捷鍵客製化**

按鍵綁定放在 `~/.config/opencode/tui.json` 的 keybinds 區塊，可查詢、可重綁、可清空預設：

```json
{
  "keybinds": {
    "leader": "<a-x>",
    "input_submit": "<cr>",
    "switch_agent": "<leader>a",
    "session_new": "<leader>n"
  }
}
```

改造原則只有一條：**把你每天按超過十次的操作，換成單手可及的鍵位**。先觀察自己一週的操作熱點，再動手綁，比一次大改更不容易彆扭。

## 本章摘要 {.unnumbered .unlisted}

- 設定分全域與專案兩個主要位置，JSONC 格式、schema 宣告開啟補全。
- 七層合併優先序：內建→全域→XDG→專案→額外檔案→代理定義→CLI 旗標，越晚套用越大。
- 自訂指令把複雜提示詞變成 `/命令`，放 `.opencode/command/` 隨版控共享。
- 快捷鍵在 tui.json 改造；先觀察熱點再綁，服務手感而不是炫技。
