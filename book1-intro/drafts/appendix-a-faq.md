# 附錄 A：常見問題排解

## 安裝與啟動

**Q：`opencode` 指令存在，但啟動後畫面亂掉或閃爍？**
終端機不支援 TUI 需要的繪圖序列。換用第 1 章推薦的現代終端機（WezTerm、Ghostty、Kitty、Alacritty）；SSH 遠端場景確認連線端的終端機模擬也支援。

**Q：Windows 原生安裝後，介面顯示異常或功能缺漏？**
官方對 Windows 的建議是 WSL2。原生路線僅作為過渡，長期使用請遷移到 WSL。

**Q：公司網路需要代理伺服器才能連外？**
為終端機設定環境變數後再啟動：

```bash
export https_proxy=http://proxy.example.com:8080
export http_proxy=http://proxy.example.com:8080
```

## 模型與連線

**Q：/connect 之後一直轉圈或回報認證失敗？**
依序檢查：金鑰是否複製完整（頭尾無空白）、帳號付款方式是否生效、系統時間是否正確（時間偏差會導致 TLS／簽章錯誤）。

**Q：回應中途斷線怎麼辦？**
直接重送訊息，代理會接續上下文。頻繁斷線時先排除代理伺服器攔截，再考慮換供應商測試是否為該家服務不穩。

**Q：可以同時接多家供應商嗎？**
可以。各供應商的金鑰各自存放，用 /models 切換即可，互不干擾。

## 使用行為

**Q：代理改壞了程式碼，但 /undo 說沒有可回退的項目？**
undo 只涵蓋本會話中代理產生的變更。若變更發生在之前的會話，請從該會話操作；若已被你手動 commit，走 Git 自己的回退流程（`git revert` 或 `git reset`）。

**Q：回答品質越來越差、開始忘記前面說的事？**
上下文接近上限的徵兆。開新會話（/new），並把必要的背景濃縮成幾句話重新交代；長期方案見第二冊第 20 章。

**Q：@語法找不到某個檔案？**
確認檔案在 OpenCode 的啟動目錄之下（它只看得到啟動位置以內的檔案）。被 .gitignore 排除的檔案也可能不在搜尋範圍。

**Q：可以讓代理執行任意指令嗎？會不會危險？**
Build 模式下代理具備指令執行能力，高風險操作會觸發權限確認。第一冊階段的原則：重要專案先 commit 再讓它動工；權限細部調校見第二冊第 21 章。
