# 第 6 章：必學指令速成

> **本章學習目標**

> - 用 /share 產生對話連結與人協作
> - 用 /models 隨任務切換模型
> - 認識其他高頻指令
>
> **預估閱讀時間**：10 分鐘
> **實作時間**：約 10 分鐘

## 6.1 /undo：後悔藥

讓代理改了東西，看完發現「不是我要的」。輸入：

```text
> /undo
  已回退 3 個檔案的變更。
  你的上一則訊息已放回輸入框，可修改後重送。
```

OpenCode 會把這一輪的所有變更回退，並把你的原始訊息重新放回輸入框——方便你修改措辭再送出一次。可以連續執行多次 /undo，逐層往回退。

## 6.2 /redo：反悔你的反悔

回退之後又覺得「其實原本的比較好」：

```text
> /redo
  已重新套用剛才回退的變更。
```

把剛才 undo 掉的變更重新套用。undo 與 redo 成對使用，你可以在不同版本之間自由來回。

> **重點**：undo/redo 的底層是 Git 快照機制，只涵蓋「透過代理產生的變更」。你自己手動改的檔案不在它的管理範圍內——養成重要變更先 commit 的習慣永遠不虧。

## 6.3 /share：分享對話

想請教同事、發問到論壇、或單純留一份紀錄：

```text
> /share
  對話已建立分享連結並複製到剪貼簿：
  https://opencode.ai/s/xK9mP2qL
```

OpenCode 會把目前對話上傳並複製一個網址到剪貼簿，打開就是完整對話（含工具呼叫過程），別人不用裝任何東西就能看。

隱私提醒：**對話預設是不公開的，share 是完全手動的動作**。含敏感資訊（客戶資料、金鑰片段、內部網址）的對話不要分享；已建立的分享連結也可以在官方網站上解除。

## 6.4 /models：切換模型

```text
> /models
  選擇模型：
    opencode/claude-sonnet-4-6        ← 目前使用
    opencode/grok-code-fast
    opencode/qwen3-coder
    freemodel/gpt-5.4
  （方向鍵移動，Enter 確認）
```

會列出你可用的模型清單，方向鍵選取即時切換。什麼時候該換？

- **長文件分析**：換上下文視窗大的模型
- **大量重複性小修改**：換便宜的模型跑量
- **關鍵邏輯設計**：換旗艦模型求穩

「任務配模型」的成本思維在第五冊會大幅展開，這裡先建立反射：狀態列看到模型名稱時，問自己一句「這個任務值得用它嗎？」

順帶一提，不進 TUI 也能查模型清單——終端機直接下：

```bash
opencode models                   # 列出全部可用模型（provider/model 格式）
opencode models zen               # 只看特定供應商
```

## 6.5 其他常用指令

| 指令 | 作用 | 使用時機 |
|------|------|----------|
| `/init` | 產生或更新 AGENTS.md | 專案結構大改之後 |
| `/themes` | 更換介面主題 | 純個人偏好 |
| `/new` 或開新會話 | 開啟全新對話 | 換話題、上下文太雜時 |
| `/help` | 查看可用操作 | 忘記指令的時候 |

斜線指令的共同點：它們是「給 OpenCode 本身的命令」，不會消耗模型額度；跟代理說話才是花費 token 的部分。

其中 /themes 與 /new 的畫面長相：

```text
> /themes
  選擇主題：
    opencode      ← 目前使用（深色）
    zenburn
    solarized
    monokai

> /new
  已開啟新會話。（舊會話仍保留，可隨時切回）
```

## 本章摘要

- /undo 回退變更並還原訊息供修改；/redo 反向套回；兩者基於 Git 快照，只管代理的變更。
- /share 手動產生對話連結，敏感內容勿分享。
- /models 即時切換模型，建立「任務配模型」的意識。
- 斜線指令本身免費，對話才計費。
