# 附錄 A：快速鍵完整對照

> 以官方文件與終端機內 `/help` 為準，版本更新可能調整。本表為第二冊範疇的完整版；入門速查見第一冊附錄 C。

## 全域操作

| 按鍵 | 作用 |
|------|------|
| Enter | 送出訊息 |
| Esc | 中斷代理目前的執行／關閉彈出視窗 |
| Ctrl+C（兩次） | 離開 OpenCode |
| Ctrl+C（一次） | 清空目前輸入 |

## 模式、模型與代理

| 操作 | 方式 |
|------|------|
| 切換 Build／Plan 模式 | Tab |
| 切換模型 | `/models` 或介面內模型選單 |
| 切換代理 | 介面內代理選單；自訂快捷鍵見下方 |

## 輸入技巧

| 按鍵 | 作用 |
|------|------|
| `@` | 呼出檔案模糊搜尋，直接引用檔案路徑 |
| `/` | 呼出指令清單 |
| 拖曳或貼上圖片 | 附圖供代理分析（第 8 章） |
| 多行輸入 | 以反斜線 `\` 結尾換行，或使用編輯器模式 |

## 快捷鍵客製化

按鍵綁定定義於 `~/.config/opencode/tui.json` 的 `keybinds` 區塊：

```json
{
  "keybinds": {
    "leader": "<a-x>",
    "switch_agent": "<leader>a",
    "session_new": "<leader>n"
  }
}
```

- `<leader>` 是可自訂的前導鍵概念，先按前導鍵再按組合鍵。
- 角括號語法：`<a-x>`＝Alt+X、`<cr>`＝Enter。
- 完整的可綁定動作清單以官方文件〈Keybinds〉為準。

改造心法複習（第 12 章）：先記錄自己一週的高頻操作，再把每天超過十次的動作綁成單手鍵位。
