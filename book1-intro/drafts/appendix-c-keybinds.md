# 附錄 C：快速鍵參考表

> 以官方文件為準，版本更新可能調整；終端機內輸入 /help 可隨時查詢。

## 全域操作

| 按鍵 | 作用 |
|------|------|
| Enter | 送出訊息 |
| Ctrl+C（兩次） | 離開 OpenCode |
| Esc | 中斷代理目前的執行／關閉彈出視窗 |

## 模式與模型

| 按鍵 | 作用 |
|------|------|
| Tab | 切換 Build／Plan 模式 |

## 輸入技巧

| 按鍵 | 作用 |
|------|------|
| @ | 呼出檔案模糊搜尋 |
| / | 呼出指令清單 |
| 拖曳圖片進視窗 | 貼上圖片路徑供代理分析 |

## 斜線指令速查

| 指令 | 作用 | 詳見 |
|------|------|------|
| /connect | 接上模型供應商 | 第 3 章 |
| /init | 產生 AGENTS.md | 第 3 章 |
| /undo | 回退代理變更 | 第 6 章 |
| /redo | 重做被回退的變更 | 第 6 章 |
| /share | 產生對話分享連結 | 第 6 章 |
| /models | 切換模型 | 第 6 章 |
| /themes | 更換介面主題 | 第 4 章 |
| /new | 開新會話 | 第 6 章 |
| /help | 查詢可用操作 | —— |

## 自訂快速鍵

OpenCode 支援 keybind 設定檔自訂。第一冊不展開，需要時參考官方文件的 Keybinds 章節：<https://opencode.ai/docs/keybinds>
